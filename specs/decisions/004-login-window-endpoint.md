# DR-004: 登录限频窗口端点确认

## 状态

已接受。
用户对“恰好 60.000 秒时，第 0 秒的尝试已移出窗口、释放一个名额”的建议回答“按建议”。
本记录仅补充 [DR-002](002-black-box-baseline-confirmation.md) 所确认基线的 identity-session-9 端点，并更新 [DR-003](003-black-box-design-review.md) 中该项未决定状态。

## 背景

- 上一轮黑盒设计保留全部 96 条需求，最终独立审阅剩四条设计缺口。
- identity-session-9 缺少精确六十秒窗口的端点预期，其余三项为场景设计遗漏。
- 用户已确认端点，继续补齐场景并独立审阅；本轮不执行应用测试。

## 决策

- 对 [[identity-session-9](../packages/identity-session.md#identity-session-9)]，时刻 t 的计数窗口为 `(t - 60 秒, t]`。
- 距当前时刻恰好六十秒的有效尝试移出计数窗口，释放一个名额；59.999 秒仍计入、60.001 秒已移出的边界与该规则一致。
- 稳定 ID 与全部 96 条需求保留，仅补充上述端点文本，其余 95 条正文保持不变。
- 继续使用 tests/delivery-acceptance/ 中的台账，基于新确认版本修补新增会议室事务、密码完整持久化范围和后续令牌生成方法，再进行独立反事实审阅。
- stage-03-black-box-scenarios 及其公开快照保持不可变，不用新结论覆盖上一轮缺口记录。

## 影响

- 需求快照版本和哈希更新，上一轮独立审阅不能作为当前设计的通过依据。
- 精确端点场景可以取得唯一预期，不从现有实现推定业务答案。
- 场景设计通过仍不代表实际应用验收通过。

# room-discovery: 会议室发现、日程与筛选

## 意图

使团队用户按日期查看空间与占用，并找到容量和设备合适的可预约会议室。

## 外部行为

### room-discovery-1

当有有效会话的用户读取会议室资料，空间查询服务应仅返回其当前所属团队 [[identity-session-4](identity-session.md#identity-session-4)] 的会议室编号、名称、位置、容量、设备和启用状态，包括供管理用途读取的停用会议室。

### room-discovery-2

当用户指定查询日期，空间查询服务应按 Asia/Shanghai 的该自然日查询占用，未指定日期时使用当前北京时间日期，无法解析的日期应被拒绝。

### room-discovery-3

当空间查询服务汇总所选日期的会议室日程，空间查询服务应仅包含与该自然日相交且未取消的预约 [[reservation-management-3](reservation-management.md#reservation-management-3)]，按开始时间升序返回。

### room-discovery-4

当团队用户查看日程，空间查询服务应按其身份展示主题：

| 查询者 | 主题显示 |
| --- | --- |
| 预约本人 | 实际主题 |
| 本团队管理员 | 实际主题 |
| 本团队其他成员 | “已预约” |

### room-discovery-5

当用户在会议室页面选择容量和设备条件，界面应仅显示已启用、容量不少于所选人数且包含所选设备的会议室，未选择某条件时不以该条件过滤。

### room-discovery-6

当用户展开会议室的当日日程，界面应展示占用时段、预约人及按访问者身份处理后的主题 [[room-discovery-4](#room-discovery-4)]。

### room-discovery-7

当界面展示会议室占用条，界面应以十五分钟间隔表示北京时间 08:00–20:00 的占用情况，取消记录不标为占用。

### room-discovery-8

当用户查看所选日期的会议室总览，界面应展示以下基于团队原始列表的数量，不因容量或设备筛选改变数量：

| 指标 | 含义 |
| --- | --- |
| 可预约会议室 | 本团队已启用会议室总数 |
| 所选日期预约 | 本团队所有会议室所选日期的有效预约数量 |
| 我的当日会议 | 当前用户在所选日期开始且未取消的预约数量 |

### room-discovery-9

当没有会议室满足筛选条件，界面应显示无匹配空间提示并保留调整筛选的入口。

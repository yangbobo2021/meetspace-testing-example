# space-administration: 会议室资料与可预约状态管理

## 意图

使本团队管理员维护空间资料与可预约状态，并保留已有预约的业务记录。

## 外部行为

### space-administration-1

当当前用户进入空间管理，空间管理服务应仅向本团队管理员开放添加和编辑会议室的操作，普通成员不得通过直接调用接口绕过限制。

### space-administration-2

当本团队管理员提交合法新会议室，空间管理服务应在其所属团队建立带独立编号的会议室，并返回保存的完整资料。

### space-administration-3

当本团队管理员提交合法会议室修改，空间管理服务应保存名称、位置、容量、设备及启用状态，后续查询应使用当前资料。

### space-administration-4

当管理员提交会议室名称，空间管理服务应要求去除首尾空格后的名称在同一团队内唯一，名称冲突不得改变已有会议室。

### space-administration-5

当管理员提交会议室资料，空间管理服务应按以下字段规则校验：

| 字段 | 规则 |
| --- | --- |
| 名称 | 字符串，去除首尾空格后为一至四十字符 |
| 位置 | 字符串，去除首尾空格后为一至八十字符 |
| 容量 | 一至一百的整数，不接受布尔值或小数 |
| 启用状态 | 布尔值，新增资料未提供时默认启用 |

### space-administration-6

当管理员提交会议室设备，空间管理服务应仅接受由显示屏、白板、视频会议、电话会议组成的列表，允许空列表，保存时去除重复设备。

### space-administration-7

当会议室被停用，空间管理服务应保留它的资料与已有预约，阻止它接受新预约 [[reservation-creation-1](reservation-creation.md#reservation-creation-1)]。

### space-administration-8

当会议室资料发生变更，空间管理服务应保持已有预约的时间、参会人数和状态不变，降低容量不自动取消原预约。

### space-administration-9

当管理员请求修改不存在或另一团队的会议室，空间管理服务应返回会议室不存在，不改变该空间资料。

### space-administration-10

当管理员重新启用会议室，空间管理服务应恢复该会议室接受新预约的资格 [[reservation-creation-1](reservation-creation.md#reservation-creation-1)]。
